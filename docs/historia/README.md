# Historia powstawania projektu

Ten folder zawiera dokumenty robocze z budowy aplikacji. Nie są potrzebne do korzystania z programu, ale pokazują, jak projekt był prowadzony: od specyfikacji, przez plan etapów, po odbiór każdego etapu i audyt.

- [SPEC.md](SPEC.md) — specyfikacja wymagań, od której zaczął się projekt.
- [PLAN.md](PLAN.md) — plan realizacji, decyzje projektowe i kryteria odbioru etapów.
- `stage-*-verification.md` — odbiór kolejnych etapów: co sprawdzono i z jakim wynikiem.
- `release-v*.md`, [v1.1-verification.md](v1.1-verification.md) — opisy lokalnych wydań.
- [USPRAWNIENIA.md](USPRAWNIENIA.md), [ANALIZA_ROZWOJU.md](ANALIZA_ROZWOJU.md) — usprawnienia i analiza dalszego rozwoju.
- [AUDYT-2026-10-16.md](AUDYT-2026-10-16.md) — końcowy audyt zapisu i interfejsu.
- [publishing.md](publishing.md) — notatki przygotowania publikacji (sprzed wyboru licencji MIT).

Dokumenty opisują stan z chwili ich powstania, więc niektóre informacje (np. o braku licencji) są już nieaktualne.
